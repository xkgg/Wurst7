# Wurst 7.56.1 / Minecraft 1.20.1 更新记录

核对日期：2026-10-18。本轮跟随官方 `1.21.11` 分支，将上次基准
`471194abbf4e97d4bcdbf13723a042c496cc5a2a` 至最新提交
`0395de014ba530c27b32dd9c7ac7131580cba29a`（Merge v7.56.1 into 1.21.11）
之间适用于 Minecraft 1.20.1 的改动移植到本分支。

Minecraft 保持 `1.20.1`，Wurst 更新为 `7.56.1`，编译产物继续使用 Java 17
字节码，保留中文名称、设置、翻译以及此前修复的盾牌回归测试。

## 功能更新

- NewChunks 增加方块和生物群系调色板检测，用未使用的空气或平原条目识别新区块，
  排除全局调色板和单值调色板，保留流体检测作为后备。
- NewChunks 在客户端主线程检查已接收的区块，不再为每个区块新建线程；
  流体扫描跳过空区段和调色板中没有流动流体的区段。
- NewChunks 忽略客户端拒收的范围外区块包，保存方块更新坐标的不可变副本，
  在世界变更和断开时清空旧数据，避免渲染阶段重置覆盖新世界的检测结果。
- 更新 NewChunks“显示原因”的中文说明，解释调色板检测没有对应的高亮方块。
- Jesus 的流体碰撞只作用于本地玩家，不再改变单人世界中其他生物的碰撞。
- NoSlowdown 的方块减速修复只作用于本地玩家，不再修改全局方块行为。
- HandNoClip 只修改本地玩家和相机实体的方块瞄准，不影响末影人等服务端生物。
- NoWeather 的降雨、天空时间和月相覆盖只作用于客户端，不影响单人服务端。
- InfiniChat 在初始化输入框时放宽长度限制，避免预填命令被截断；提交长命令和
  Wurst 命令时保留完整内容，普通聊天仍遵守原版 256 字符限制。
- 聊天输出事件在原版规范化后触发，修改后的消息继续走原版发送路径；
  被取消的消息仍加入历史记录。
- 连接级数据包输出事件改为包装统一发送入口，移除共享事件队列，支持替换、
  取消和嵌套发送。1.20.1 的统一入口为双参数 `send`，新版本的三参数签名不适用。
- NoTelemetry 在每次发送时读取当前开关，使已缓存的发送器也能立即响应切换；
  不再覆盖账号的原版遥测 API 权限判断。
- 缩放只调整本次鼠标输入灵敏度，不再反复修改并恢复用户保存的灵敏度设置。
- PortalGUI 直接修改传送门检查读到的界面值，不再临时改写客户端当前界面字段。
- FeedAura 不再单向关闭其他战斗光环；AntiSpam 使用文本副本追加计数。
- 简化相机距离开关处理和已加载区块遍历，移除官方已废弃的 VanillaTweaks
  Twinkling Stars 警告及其资源包扫描器。

## 兼容性取舍

- 保持 Yarn `1.20.1+build.10`、Fabric API `0.92.12+1.20.1`、Fabric Loader
  `0.19.5`、Loom `1.17.21`、Gradle `9.8.1` 和 Spotless `8.10.4`。
- 保留 1.20.1 编译仍需的 JSR305 依赖，不跟随新版本删除。
- 保留旧版适用的兼容钩子、资源包来源校验和本地 Mixin 组织方式；上游的
  Mojang 映射名称调整、26.2 专属兼容代码删除和单纯移动包路径不机械移植。
- 客户端测试增加可选 `-Pwurst.e2eTestDir=...` 参数，用于独立测试目录；
  GitHub Actions 默认仍使用 `run`。
- 属性切换回归将同刻伤害机制验证与实际启用后的切换、攻击、换回验证分开，
  避免结果依赖网络任务恰好在同一个服务端游戏刻处理。
- 本地碰撞测试结束后将玩家复位到平台，避免从灵魂沙换回石头时陷入方块，
  影响后续 AutoFarm 等场景。

## 验证

- 通过 `spotlessApply build runEndToEndTest --stacktrace --warning-mode=fail
  --no-configuration-cache`，测试目录使用
  `-Pwurst.e2eTestDir=build/e2e-7.56.1`，不改动现有 `run` 目录。
- 14 项 JUnit 单元测试全部通过，无失败或跳过。
- 原有 AutoMine、Freecam、NoFall、XRay、命令与活塞测试，以及 28 项回归场景
  全部通过，包含七项新增回移测试、AutoFarm、属性切换、盾牌和 NoWeather。
- 新增回移测试覆盖本地与服务端碰撞隔离、长命令与聊天事件、数据包替换/取消/
  嵌套发送、NewChunks 调色板与流体检测、范围外区块、PortalGUI、FeedAura、
  已缓存遥测发送器的开关行为。
- 构建时执行 Mixin 审计；使用本机 JDK 22.0.1 运行客户端测试。检查最终 JAR：
  Minecraft 依赖固定为 `1.20.1`，Java 要求为 `>=17`，796 个 class 的版本均为
  `61`（Java 17）。本轮未单独使用 Java 17 启动游戏。
- 构建日志：`build/backport-7.56.1-full-restored.log`。

输出文件：`Wurst-Client-v7.56.1-MC1.20.1.jar` 和
`Wurst-Client-v7.56.1-MC1.20.1-sources.jar`。
