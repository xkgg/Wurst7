# Wurst 7.57 / Minecraft 1.20.1 更新记录

核对日期：2026-11-21。同步官方 `1.21.11` 分支截至 2026-11-18 的提交
`11c7b5e76d57500ccb2544aaea3d9f2b9aebff32`
（Merge branch '26.1.2' into 1.21.11）。
上次同步基准为 `21ece1499677e2948e245f6cd6b7566abbf2afa3`。

Wurst 更新为 `7.57`，Minecraft 保持 `1.20.1`，继续生成 Java 17
字节码，并保留现有中文功能名、设置键和配置值。

## 上游同步

- AimAssist、KillauraLegit 使用共享鼠标瞄准控制器，改善低灵敏度、逐帧插值、
  手动转向保留和忽略鼠标输入的行为；AimAssist 默认速度改为每秒 300 度。
- FOV 使用真实空间夹角，攻击优先级仍按转头距离排序；将视线检查纳入候选
  筛选，避免被遮挡目标阻止选择可见目标。
- Killaura 在冷却期间持续选择和显示目标，PreMotion 根据最新冷却状态决定
  是否转向及攻击；KillauraLegit 在无目标或使用物品时仍推进攻击计时。
- Killaura、KillauraLegit、ClickAura、MultiAura、FeedAura 接入瞄准位置设置，
  其中 FeedAura 的交互命中点与所选瞄准位置保持一致。
- 合并攻击优先级设置，并兼容旧配置中的“生命值”和“血量”；保留各功能原有
  中文优先级、FOV 设置键。修复排除部分枚举选项后无法正常循环切换的问题。
- TriggerBot 使用服务器已报告的朝向检测目标；KillauraLegit 与 AutoFish
  双向互斥，避免同时改变视角。
- 事件监听注册去重，派发时复制快照，支持回调中增删监听器。
- 更新旋转角度、转头、插值、命中结果工具和自动钓鱼调用；同步采矿筛选、
  范围平方计算及服务器清理默认关闭批量重命名的改动。
- 补齐新通用设置说明的中文翻译，保留已有翻译内容，并按英文键顺序排列
  各语言文件。测试客户端启动时将主音量设为零。

## 版本取舍

- 保持 Yarn `1.20.1+build.10`、Fabric Loader `0.19.5`、
  Fabric API `0.92.12+1.20.1`、Loom `1.17.21`。
- 跟进官方 Gradle `9.9.1`（包括 wrapper JAR）及 Spotless `8.11.0`。
- 鼠标、碰撞箱、网络包和游戏测试继续使用 1.20.1 接口；没有引入
  Minecraft 1.21.11 专用依赖或新版物品组件。
- 新增旋转数学单元测试，以及 FOV、旧中文配置、视线筛选、攻击时序、
  瞄准位置、鼠标输入、AutoFish 互斥和事件快照客户端回归场景。
