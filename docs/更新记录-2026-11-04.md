# Wurst 7.56.2 / Minecraft 1.20.1 更新记录

核对日期：2026-11-04。同步官方 `1.21.11` 分支截至 2026-11-03 的提交
`21ece1499677e2948e245f6cd6b7566abbf2afa3`
（Merge branch 'refs/heads/26.1.2' into 1.21.11）。
上次同步基准为 `d27a338c8d30c02738e78f4758bf100e4a75b573`。

Wurst 更新为 `7.56.2`，Minecraft 保持 `1.20.1`，继续生成 Java 17
字节码，并保留现有中文功能名、设置值和翻译。

## 上游同步

- 修复 NameProtect 在断开连接、世界已经清空时的崩溃。
- 将 AimAssist、Killaura、KillauraLegit 和 FeedAura 的瞄准更新移至
  PreMotion，使用实体最新位置，并在发送移动包后恢复客户端视角。
- 修复 TP-Aura 自定义攻击速度仍受原版冷却限制的问题。
- 修复数据包潜行在切换模式、骑乘和关闭功能后遗留潜行状态的问题，
  使用 1.20.1 的 `ClientCommandC2SPacket` 恢复玩家实际输入。
- 修复 Freecam 覆盖全景截图各面的旋转方向，继续保留游离相机位置。
- 按原版属性运算顺序计算物品属性，读取物品堆栈的 NBT 覆盖值，并处理
  属性缺失、重复 UUID、装备槽和原版属性限幅。
- AutoSword、AutoArmor 使用更新后的属性计算，保留 1.20.1 的目标附魔伤害
  和护甲材质比较规则。
- 用作用于原始声明方法的 Mixin 注入替换相关继承覆写，覆盖击退、空中移动、
  飞行、高跳、SafeWalk、Step 和容器按钮；骑乘时也触发 Pre/PostMotion。
- 高跳按原版重力和阻力反推所需初速度，Step 不再覆写玩家原始台阶高度，
  并整理自动跳跃检查和 Liquids 射线处理。
- 跟进 HitResult 类型判断清理，补充瞄准位置说明的中英文翻译。
- 修复云端翻译检查发现的中文键顺序问题：按英文文件重排现有 471 条翻译，
  并验证键集合及所有翻译内容完全一致。

## 版本取舍

- 保持 Yarn `1.20.1+build.10`、Fabric Loader `0.19.5`、
  Fabric API `0.92.12+1.20.1`、Loom `1.17.21`、Gradle `9.8.2`、
  Spotless `8.10.4`。
- 使用 1.20.1 的 NBT、装备属性、移动事件及网络协议接口。
- 不引入新版 Minecraft 的物品组件、重锤或仅针对 26.3 及以后版本的
  InputFaker 修复；1.20.1 中没有这些接口。
- Reach 已使用现有 1.20.1 射线距离钩子，继续沿用该实现。
