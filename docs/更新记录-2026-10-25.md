# Wurst 7.56.1 / Minecraft 1.20.1 更新记录

核对日期：2026-10-25。本轮核对官方 `1.21.11` 分支截至 2026-10-24 的提交
`0f11f5bd6f04c1f7cd11966ef4caa1cc16ff8db5`（Merge branch '26.1.2' into
1.21.11），跟进上次记录基准 `0395de014ba530c27b32dd9c7ac7131580cba29a`
之后适用于 1.20.1 的改动，并补齐回移兼容性修复。

Minecraft 保持 `1.20.1`，Wurst 保持 `7.56.1`，客户端继续使用 Java 17
字节码，保留现有中文名称、设置和翻译。

## 上游同步

- 跟进 `8d7e1285c`：删除 `RotationUtils.getEyesPos()`，全部调用改用原版
  `getEyePos()`，同时更新本分支的 FeedAura 等额外调用。
- 跟进 `1d174453f`：删除 `MathUtils.clamp()` 的三个重载，滑块和缩放改用
  1.20.1 已有的 `MathHelper.clamp()`，避免引入要求 Java 21 的 `Math.clamp()`。
- 核对其余新增提交：新版本 Fabric API、Sodium、映射名称和 Mixin 包路径
  调整没有额外适用于 1.20.1 的功能行为需要移植。

## 兼容性修复

- AutoSign 改用 1.20.1 实际存在的 `init()V` HEAD 注入，与当前官方
  `1.21.11` 实现一致；修复此前 `setInitialFocus()V` 目标不存在的问题。
  普通告示牌和悬挂告示牌均保留中文输入、记忆文字和自动关闭行为。
- TemplateTool 补齐当前官方实现的空名称与非法路径检查：清除之前的文件路径、
  禁用完成按钮，阻止 Enter 提交无效名称，输入恢复有效后重新启用。
  保留 1.20.1 的输入框初始焦点和调整窗口后的焦点处理。
- 补齐 1.20.1 的相机方块遮挡处理：在现有 `InGameOverlayRendererMixin`
  中使用本版的 `getInWallBlockState` 接口，Freecam 开启时去掉堵墙覆盖层；
  CameraNoClip 仅在第三人称去掉覆盖层，第一人称保留正常行为。
  此项为旧版兼容性补齐，不计作本轮官方 `1.21.11` 新增功能。

## 版本取舍

- 保持 Yarn `1.20.1+build.10`、Fabric Loader `0.19.5`、Fabric API
  `0.92.12+1.20.1`、Loom `1.17.21`、Gradle `9.8.1`、Spotless `8.10.4`。
- 保留 1.20.1 所需的 JSR305 和现有兼容钩子；不机械迁移新版本的映射名称、
  渲染类、包路径及专属依赖。

- 通过 `spotlessApply build runEndToEndTest --offline --stacktrace
  --warning-mode=fail --no-configuration-cache`；客户端使用独立目录
  `-Pwurst.e2eTestDir=build/e2e-upstream-2026-10-25`，保留现有 `run` 目录。
- 14 项 JUnit 单元测试全部通过，无失败或跳过。
- 原有 AutoMine、Freecam、NoFall、XRay、命令与活塞测试，以及 31 项具名
  客户端回归场景全部通过，并完成 Mixin 审计。
- 新增 `BackportAutoSign`：验证普通及悬挂告示牌的中文输入、缓存文字、
  单次重放数据包、自动关闭和禁用后的缓存清理；测试拦截告示牌数据包。
- 新增 `BackportTemplateNames`：验证初始焦点、输入、空名称、包含 NUL 的
  非法路径、Enter 拦截、恢复有效名称和窗口调整后的焦点；测试不保存文件。
- 新增 `BackportCameraOverlay`：验证正常堵墙、Freecam 开关及 CameraNoClip
  不同视角下的覆盖层检测；测试结束后恢复方块和视角。
- 最终 JAR 的 Minecraft 依赖固定为 `1.20.1`，Java 要求为 `>=17`；
  796 个 class 的版本均为 `61`（Java 17）。
- 本机使用 JDK `22.0.1` 构建并运行客户端；本轮未单独使用 Java 17 启动游戏。
  构建日志：`build/upstream-2026-10-25-verified.log`。
