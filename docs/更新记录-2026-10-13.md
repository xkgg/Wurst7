# Wurst 7.56 / Minecraft 1.20.1 更新记录

本轮以官方 `1.21.11` 分支提交 `471194abbf4e97d4bcdbf13723a042c496cc5a2a` 为比较基准，移植适用于 Minecraft 1.20.1 的修复，保持 Wurst 7.56、Java 17 字节码及现有中文定制。

## 功能修复

- 修复自动拿取反向偷取时操作不可修改列表导致的异常。
- 修复聊天翻译请求或解析失败时的空值异常，保留原文发送后备逻辑，增加读取超时。
- 自动农场挖掘遵守朝向和挥手设置，仅关闭朝向时允许创造模式批量挖掘。
- 修复缠怨藤、垂泣藤在原植物消失后的补种支撑面检查。
- 创造模式缺少种子时通过空背包栏位提供种子，生存模式和背包已满时不提供。
- 自动农场右键收获前切换非骨粉物品，等待背包交换完成，避免误施肥。
- 更新熊猫、山羊、末影人、僵尸猪灵的平静状态过滤。
- 修复野生狐狸信任列表包含空值导致的宠物误判。
- NoBackground 的所有界面模式覆盖暂停菜单和设置界面。
- ClickGUI 的 UI 设置增加 Wurst 选项入口。
- Alt Manager 异步加载在线 UUID、账号资料和皮肤，失败时保留默认头像。

## 中文与维护

- 补充 55 条设置说明，覆盖 AimAssist、AnchorAura、AntiAFK、Follow、MobSpawnESP、RemoteView 和通用过滤器。
- 翻译器保留中文优先并加入英文基础回退，原有中文条目全部保留。
- Fabric Loader 更新至 `0.19.5`，Fabric API 更新至 `0.92.12+1.20.1`。
- Minecraft 产物依赖明确限定为 `1.20.1`；保持 Loom 1.17.21、Gradle 9.8.1。
- 更新 README 的构建 JDK 与 IDE 任务说明，以及 Eclipse 脚本。
- 手动 Build 和发布构建增加依赖解析重试；发布前执行完整 build。
- 客户端测试增加 15 分钟超时和运行日志上传。
- 保留上海时区、工作流运行记录清理、VirusTotal 配置及无 backport 的输出文件名。
